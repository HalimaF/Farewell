# Farewell Celebration Invitation 🎓

A fun, interactive farewell invitation website for the CS Department at Kinnaird College Lahore. This website features a playful "No" button that always says "Yes" and beautiful animations with background music.

## ✨ Features

- **Interactive RSVP Buttons**: Both "Yes" and "No" buttons lead to event details
- **Cute Background Music**: Auto-playing upbeat melody that creates celebratory vibes
- **3D Effects**: Perspective transforms, animated floating orbs, and particle background
- **Glass-Morphism Design**: Modern frosted glass cards with backdrop blur effects
- **Responsive Design**: Optimized for desktop, tablet, and mobile screens
- **Confetti Animation**: Celebratory confetti shower on RSVP confirmation
- **Event Details**: Displays venue, date, time, and event information

## 🎨 Design Highlights

- **Color Palette**: Soft pastels (pinks, purples, blues, greens)
- **Typography**: Playfair Display (headings) & DM Sans (body)
- **Animations**: Smooth transitions, floating particles, wobbling effects
- **Music**: Upbeat celebratory melody that loops every 4.5 seconds

## 🎵 Background Music

The website features auto-playing background music created with Web Audio API:
- Generated melody using sine waves
- Upbeat, celebratory progression
- Low-pass filter for warm, pleasant tone
- Volume set to 12% for non-intrusive listening
- Toggle button to pause/resume (🎵/🎶)

## 🚀 How to Use

1. Open `index.html` in a modern web browser
2. Enjoy the cute background music and animations
3. Click "Yes, of course 💕" or "No" to confirm attendance
4. View event details on the success screen
5. Use the music toggle button (bottom-right) to pause/resume music
